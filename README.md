# 🧮 Calculadora em Python

Projeto simples de calculadora desenvolvido em Python, com operações básicas:

## 🔧 Funcionalidades
- Soma
- Subtração
- Divisão
- Multiplicação
- Validação de divisão por zero

## 💻 Tecnologias
- Python

## 🚀 Como executar

1. Instale o Python na sua máquina
2. Baixe o projeto
3. Execute o comando abaixo no terminal:

```bash
python calculadora.py
